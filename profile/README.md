# Pramaan OSS

Open-source building blocks to launch your products and ideas to the market quickly.

- **One API, no provider wiring.** Call a capability; we handle the providers.
- **Best output, lowest cost.** Every call is routed to the provider that delivers the result at the lowest cost, and falls back automatically when one fails.
- **Open.** Read it, run it yourself, switch providers any time. Licensed AGPL-3.0.
