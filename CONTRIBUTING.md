# Contributing to Pramaan OSS

Thanks for helping. This guide applies to every repository in the organization unless a repo has its own.

## Quick start

1. Open an issue first for anything bigger than a typo, so we can agree on the approach.
2. Fork the repo and create a branch from `main`.
3. Make one focused change. Small pull requests get reviewed faster.
4. Run the repo's checks (usually `pnpm check`) and make sure they pass.
5. Open a pull request and fill in the template.

## What makes a good pull request

- One purpose per pull request.
- A clear title and a short description of what changed and why.
- Tests for new behavior and bug fixes.
- No secrets, keys or tokens in the code, history or screenshots.

## Commit messages

Use the imperative mood and keep the first line under 72 characters, for example `Add retry to the search adapter`.
