# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Use GitHub's private reporting: open the affected repository, go to the **Security** tab, and choose **Report a vulnerability**. Include what you found, how to reproduce it, and the impact.

We aim to acknowledge reports within 3 working days and to share a fix plan within 10.

## Scope

All repositories in the Pramaan-OSS organization. Never include real keys or customer data in a report.

## Supported versions

The latest release of each project receives security fixes.
